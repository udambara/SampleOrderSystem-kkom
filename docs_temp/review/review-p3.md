# Review — Phase 3

## 피드백

`logs` 폴더가 어디 생성되는지 안 보인다는 질문.

## 확인 내용

- `data/`, `logs/`는 실행 파일(`.exe`)을 실행하는 **현재 작업 디렉터리** 기준 상대경로(`data/...`, `logs/order_events.log`)에 생성됨. 실행 위치에 따라 결과 폴더 위치가 달라짐 (예: Visual Studio Win32 빌드로 실행하면 `ProjectSampleOrderSystem/Debug/` 아래에 생성됨)
- 두 폴더 모두 `.gitignore`에 등록되어 있어 git에는 잡히지 않음 (의도된 동작)
- `logs/`가 안 보였던 이유: `Logger`는 실제로 주문 상태전환이 발생할 때만 파일을 생성하는 지연 생성 방식인데, 그 시점까지 시료등록(Phase 2)만 실행했고 시료주문(Phase 3, 상태전환 발생 지점)은 아직 실행하지 않았기 때문
- 이후 사용자가 직접 시료주문(메뉴 2번)으로 주문 1건(`ORD-20260715-0001`, 하이닉스, 수량 20)을 접수해 정상적으로 `RESERVED` 주문이 생성되고 로그가 남는 것을 확인함

## 결론

코드 변경 없음. 동작은 설계대로였고, 폴더 생성 위치와 지연 생성 방식에 대한 설명으로 해결됨.
