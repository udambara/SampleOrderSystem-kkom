# Test Plan — Phase 2 (시료관리)

## 사전조건

- Phase 1 완료, `data/samples.json`이 빈 상태

## 테스트 시나리오

### TC2-1. 시료등록 성공

1. 시료관리 → 시료등록 진입
2. 시료ID=`S001`, 이름=`실리콘웨이퍼`, 평균생산시간=`10`, 수율=`0.9` 입력
3. 예상 결과: 등록 성공 메시지 출력, `data/samples.json`에 `stock=0`으로 저장됨

### TC2-2. 중복 시료ID 등록 방지

1. TC2-1 이후, 동일 시료ID(`S001`)로 재등록 시도
2. 예상 결과: 에러 메시지 출력, 기존 데이터가 덮어써지지 않음

### TC2-3. 시료조회

1. 시료관리 → 시료조회 진입
2. 예상 결과: 등록된 모든 시료(ID/이름/평균생산시간/수율/재고)가 목록으로 표시됨, `S001`의 재고는 `0`

### TC2-4. 시료검색 — 이름, 일치하는 경우

1. 시료관리 → 시료검색 진입 → "이름으로 검색" 선택, 검색어로 `실리콘` 입력
2. 예상 결과: `S001` 시료가 검색 결과에 포함됨

### TC2-5. 시료검색 — 이름, 일치하지 않는 경우

1. 시료검색 → "이름으로 검색" 선택, 검색어로 존재하지 않는 이름(`텅스텐카바이드`) 입력
2. 예상 결과: "등록된 시료가 없습니다" 메시지 출력

### TC2-6. 시료검색 — 시료ID, 일치하는 경우

1. 시료검색 → "시료ID로 검색" 선택, 검색어로 `S001` 입력
2. 예상 결과: `S001` 시료 1건만 결과에 표시됨

### TC2-7. 시료검색 — 시료ID, 일치하지 않는 경우

1. 시료검색 → "시료ID로 검색" 선택, 검색어로 존재하지 않는 ID(`S999`) 입력
2. 예상 결과: "등록된 시료가 없습니다" 메시지 출력

## 완료 기준

- 위 7개 시나리오 모두 통과
