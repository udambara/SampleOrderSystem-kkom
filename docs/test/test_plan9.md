# Test Plan — Phase 9 (관리자모드)

## 사전조건

- Phase 5, Phase 6 완료
- 시료 `S001`(실리콘웨이퍼) 등록되어 있음, 재고는 0

## 테스트 시나리오

### TC9-1. 테스트 주문 생성 — 생산라인이 비어 있는 경우

1. 메인 메뉴 8번(관리자모드) 진입
2. 테스트 주문 생성: 시료ID=`S001`, 고객명=`QA`, 수량=`5`, 생산시간(초)=`5` 입력
3. 예상 결과:
   - 주문이 즉시 `PRODUCING` 상태로 생성됨, `shortageQty=5`, `totalProductionSeconds=5`
   - 생산라인이 비어 있었으므로 `productionStartEpochSec`가 즉시 채워짐 (생산현황표기에서 확인)

### TC9-2. 5초 경과 후 자동 완료

1. TC9-1 이후 5초 이상 대기한 뒤 임의의 메뉴 진입 (Tick 트리거)
2. 예상 결과: 해당 주문이 `CONFIRMED`로 전환되고 시료 `S001` 재고가 5만큼 증가

### TC9-3. 테스트 주문 생성 — 생산라인이 사용 중인 경우

1. 생산라인이 사용 중인 상태(예: 다른 주문이 생산중)에서 관리자모드로 두 번째 테스트 주문 생성
2. 예상 결과: 새 주문이 `PRODUCING` 상태이지만 `productionStartEpochSec=0`으로 대기열 맨 뒤에 등록됨 (대기주문확인에서 FIFO 순서로 확인)

### TC9-4. 존재하지 않는 시료ID로 테스트 주문 생성 시도

1. 시료ID=`S999`(미등록)로 테스트 주문 생성 시도
2. 예상 결과: 에러 메시지 출력, 주문이 생성되지 않음

### TC9-5. 로그 조회

1. TC9-1, TC9-2 진행 후 관리자모드 → 로그 조회 진입
2. 예상 결과: 해당 주문번호에 대해 `-`→`PRODUCING`, `PRODUCING`→`CONFIRMED` 전환 기록이 시각과 함께 최근 순으로 표시됨

### TC9-6. 로그 없음 케이스

1. `logs/order_events.log`가 없는 상태(최초 실행)에서 로그 조회 진입
2. 예상 결과: "기록된 로그 없음" 출력, 에러 없이 정상 종료

## 완료 기준

- 위 6개 시나리오 모두 통과
- 관리자모드로 생성한 주문과 정상 승인 플로우(Phase 4)로 생성한 주문이 동일한 생산큐에서 충돌 없이 FIFO로 처리됨
