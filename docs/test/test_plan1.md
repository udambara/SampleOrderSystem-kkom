# Test Plan — Phase 1 (기반 구축)

## 사전조건

- 최초 실행 (data/ 폴더 없음)

## 테스트 시나리오

### TC1-1. 최초 실행 시 데이터 파일 자동 생성

1. `data/` 폴더 및 `data/samples.json`, `data/orders.json`이 없는 상태에서 프로그램 실행
2. 예상 결과: `data/samples.json`, `data/orders.json`이 자동 생성되고 내용은 빈 배열(`[]`)

### TC1-2. 메인 메뉴 표시 및 네비게이션

1. 프로그램 실행
2. 예상 결과: 6개 메인 메뉴(시료관리/시료주문/시료승인·거절/모니터링/출고처리/생산라인)와 종료 옵션이 표시됨
3. 각 메뉴 번호를 순서대로 입력해 진입
4. 예상 결과: 스텁 컨트롤러로 진입해 "미구현" 안내가 출력되고, 다시 메인 메뉴로 복귀함

### TC1-3. 잘못된 메뉴 입력 처리

1. 존재하지 않는 메뉴 번호(예: 99) 또는 숫자가 아닌 값 입력
2. 예상 결과: 에러 메시지 출력 후 메인 메뉴 재표시 (프로그램 비정상 종료 없음)

### TC1-4. 종료

1. 종료 메뉴 선택
2. 예상 결과: 프로그램이 정상 종료됨

## 완료 기준

- 위 4개 시나리오 모두 통과
- 재실행 시 기존 `data/*.json`이 초기화되지 않고 유지됨
