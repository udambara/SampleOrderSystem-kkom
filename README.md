# SampleOrderSystem

반도체 시료(Sample) 관리 프로그램. 고객의 시료 주문이 들어오면 재고를 확인해 필요한 만큼 생산한 뒤 출고하는 콘솔 기반 애플리케이션입니다.

## 이 프로그램이 하는 일

시료 등록부터 주문 접수, 승인/거절, 생산, 출고까지 이어지는 전체 흐름과, 그 과정을 한눈에 파악할 수 있는 모니터링 기능을 하나의 콘솔 프로그램으로 제공합니다.

## 메인 메뉴

1. **시료관리** — 시료 등록 / 목록 조회 / 이름 검색
2. **시료주문** — 고객 주문 접수 (예약)
3. **시료승인/거절** — 접수된 주문에 대한 승인·거절 처리
4. **모니터링** — 상태별 주문 수 및 시료별 재고 현황 확인
5. **출고처리** — 승인된 주문의 출고 실행
6. **생산라인** — 생산 현황 및 대기 주문(FIFO) 확인
7. **종료**
8. **관리자모드** — 테스트용 주문을 즉시 생산중 상태로 생성(가속평가)하고, 주문 상태전환 로그를 조회

## 핵심 동작 방식

- 고객이 주문을 넣으면(`RESERVED`) 담당자가 승인 여부를 결정합니다. 이때 재고가 충분하면 바로 `CONFIRMED`, 부족하면 부족분을 생산하도록 자동으로 생산라인에 등록되며 상태가 `PRODUCING`으로 바뀝니다.
- 생산라인은 FIFO 큐로 동작하며, 시료의 수율과 평균 생산시간을 반영해 실생산량과 총 생산시간을 계산합니다. 생산이 끝나면 재고에 반영되고 주문은 `CONFIRMED`로 전환됩니다.
- `CONFIRMED` 상태의 주문은 출고처리를 통해 재고를 차감하고 `RELEASE` 상태로 마감됩니다.
- 모든 주문 상태전환은 로그 파일(`logs/order_events.log`)에 기록되어 추적할 수 있습니다.
